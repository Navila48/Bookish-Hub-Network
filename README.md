# 📚 Book Social Network

A full-stack web application that enables users to manage personal book collections and interact with a community through a secure and scalable borrowing system.

Built with **Spring Boot + Angular**, this project demonstrates modern backend architecture, secure authentication, and production-ready development practices.

---

## 🚀 Live Highlights

- 🔐 Secure authentication using **JWT & Spring Security**
- 📧 Email-based account activation workflow
- 📖 Full CRUD operations for book management
- 🔄 Real-world borrowing & return approval system
- 🧩 Clean architecture with separation of concerns
- 🐳 Dockerized and CI/CD ready

---

## 🧠 Key Features

### 👤 Authentication & User Management
- User registration with validation
- Email verification using secure activation codes
- JWT-based login and session handling
- Role-based access control (via Keycloak)

### 📚 Book Management
- Add, update, share, and archive books
- Ownership-based access control
- Pagination and optimized API responses

### 🔁 Borrowing Workflow
- Borrow books with availability checks
- Return borrowed books
- Owner approval for returned books

---

## 🏗️ Tech Stack

### Backend
- **Spring Boot 3**
- **Spring Security 6**
- **JWT Authentication**
- **Spring Data JPA (Hibernate)**
- **Bean Validation (JSR-303)**
- **Keycloak**
- **OpenAPI / Swagger**
- **Docker**

### Frontend
- **Angular**
- Component-based architecture
- Lazy loading modules
- Route guards for authentication
- Bootstrap for responsive UI
- OpenAPI Generator for API integration

### DevOps
- **Docker & Docker Compose**
- **GitHub Actions (CI/CD)**

---

## 🧩 Architecture Overview

- RESTful API design following best practices
- Layered architecture (Controller → Service → Repository)
- DTO pattern for clean data transfer
- Centralized exception handling
- Environment-based configuration using Spring Profiles
